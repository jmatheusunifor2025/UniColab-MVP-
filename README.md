# UniColab-MVP-

Frontend do protótipo UniColab.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Run the app:
   `npm run dev`

The app runs at http://localhost:3001.
